# Трекер чтения вслух

Android-приложение: вы читаете текст вслух, приложение **офлайн** слушает, находит по распознанной речи место в тексте
и подсвечивает слово, на котором вы сейчас находитесь. По умолчанию загружена «Одиссея» в переводе Жуковского
(`app/src/main/assets/odyssey_zhukovsky.txt`, 24 песни и примечания).

## Установка APK

1. Скопируйте APK на телефон (Android 7.0 и новее). Есть две сборки:
   - **полная** (`./gradlew assembleDebug`, ≈55 МБ): модель вшита, интернет не нужен совсем;
   - **облегчённая** (`-PbundleModel=false`, ≈8 МБ): при первом запуске один раз скачивает модель (≈46 МБ) с сайта Vosk,
     дальше работает офлайн. Для неё приложению разрешён доступ в интернет, больше ни для чего он не используется.
2. Откройте файл. Android попросит разрешить установку из этого источника («Установка неизвестных приложений») — разрешите.
   Play Protect может предупредить, что приложение не из магазина: подпись у сборки отладочная.
3. При первом запуске приложение один раз распакует (или скачает и распакует) модель распознавания (≈90 МБ на диске, до минуты) и спросит доступ к микрофону.
   Если загрузка не удалась, кнопка «Старт» превращается в «Повторить загрузку».
4. Нажмите **Старт** и читайте вслух.

## Как пользоваться

- Текущее слово подсвечено ярко, прочитанное приглушено, экран сам прокручивается. Экран не гаснет.
- **Долгое нажатие на слово** — «начать отсюда». Так же можно вернуть подсветку, если она потерялась.
- **Оглавление** — переход по песням. Позиция запоминается между запусками (отдельно для каждого файла).
- **Файл** — открыть свой `.txt`, `.html` или `.mht` (кодировка UTF-8 / windows-1251 определяется сама,
  теги HTML и служебные части MHT вычищаются; со страниц lib.ru берётся только само произведение).
  Номера строк вида `[5]`, `[10]` показываются серым и в сопоставлении не участвуют, заголовки («ПЕСНЬ ПЕРВАЯ») — тоже.
- **Настройки**: тёмная/светлая тема, чувствительность микрофона, «подсказывать распознавателю слова из текста».
- Внизу: уровень микрофона, что слышит распознаватель, статистика — слов прочитано, слов/мин, время.

## Как это работает

**Распознавание.** Офлайн Vosk, модель `vosk-model-small-ru-0.22`. Микрофон `VOICE_RECOGNITION`, 16 кГц моно, включаются
аппаратные `AutomaticGainControl` и `NoiseSuppressor` (если есть), поверх — программное усиление тихого сигнала
(медленная АРУ с ограничителем; сила регулируется «чувствительностью»). Поток не прерывается на паузах: фразы
заканчивает сам Vosk, а промежуточные результаты (partial) двигают подсветку по ходу слова.

**Ограничение словаря.** Распознавателю подсказываются слова из окна текста вокруг позиции
(≈300 слов: немного назад и ≈250 вперёд, плюс `[unk]`, с вариантами через «ё», потому что словарь модели пишет «её», а книги «ее»).
Окно перестраивается вместе с позицией. Если подсветка долго не подтверждается (читатель ушёл за пределы окна),
ограничение автоматически снимается, и после первого подтверждения возвращается.

**Сопоставление — подсветка двигается только при уверенности** (`tracking/TextTracker.kt`):

- одно слово ничего не значит: нужны **4–6 последних распознанных слов подряд**, совпавших с текстом нечётко
  (прощаются другие окончания и буква-другая), средняя похожесть слов ≥ 0,90, допускается **один пропуск или одно лишнее слово**;
- слова должны быть содержательными (≥ 14 букв суммарно либо 6 слов): «и в на не» ничего не подтверждают,
  а короткое слово (до 3 букв) в хвосте — слабое доказательство, на нём подсветка не останавливается;
- сначала поиск **рядом**: 200 слов вперёд и 50 назад; перечитывание назад требует 5 слов;
- **далёкий прыжок** — только при совпадении **8+ слов подряд** (индекс по основам слов, поиск по всей книге);
- слова новой фразы дописываются к хвосту предыдущей, поэтому после паузы подсветка продолжается сразу;
- мусор, кашель, паузы и чужая речь не дают подряд совпавших слов — подсветка стоит на месте.

## Эксперимент: ограничивать словарь или нет

Сравнение на синтезированной речи (Piper, 4 голоса × 6 отрывков, условия: чисто / тихо с усилением / шумно / тихо и шумно),
поток результатов Vosk прогнан через настоящий трекер. Скрипты — в `tools/vosk-experiment`.

| Словарь распознавателя | точность слов | подсветка в пределах 3 слов в конце строки | ложные сдвиги: чужая речь (из 8) | читают другое место (из 24) |
|---|---|---|---|---|
| без ограничения | 0,57 | 0,57 | 0 | 0 |
| **слова окна ≈300 + [unk] (выбрано)** | **0,68** | **0,69** | **0** | **0** |
| слова окна ≈100 | 0,71 | 0,75 | 0 | 0 |
| фразы по 2 слова | 0,86 | 0,88 | 1 | 1 |
| фразы по 3 слова | 0,87 | 0,91 | 2 | 3 |
| фразы по 4 слова | 0,87 | 0,92 | 2 | 2 |
| строки текста как фразы | 0,86 | 0,94 | 4 | 4 |

Ограничение словарём слов даёт +11 п.п. к точности и +12 п.п. к попаданию подсветки без единого ложного сдвига.
Фразовые варианты ещё точнее, но «притягивают» чужую речь к тексту и сдвигают подсветку, что противоречит главному требованию,
поэтому не используются. Окно ≈100 чуть точнее, но оставляет мало запаса при быстром чтении и перескоках, выбрано ≈300.
Громкость и шум на точность влияют слабо (Vosk к ним устойчив); программное усиление добавляет 1–2 п.п. на тихой речи.

## Ограничения

- Всё измерено на **синтетической** речи и не проверялось на живом человеке и на реальном телефоне: эмулятора в сборочной среде нет.
  Экран проверен на JVM (Robolectric), распознавание — на настольном Vosk.
- Модель `small-ru` — компактная: на архаичной лексике и именах (Телемах, Антиной) она ошибается и часть слов выпадает;
  алгоритм рассчитан на это (пропуски, неверные окончания), но подсветка может отставать на 1–2 слова.
- Числа цифрами в тексте с распознанной речью («двадцать пять») не совпадут.
- Приложение слушает только на экране: в фоне микрофон Android не отдаёт.
- Сборка подписана отладочным ключом.

## Сборка и тесты

```bash
cd android
export ANDROID_HOME=/путь/к/android-sdk        # платформа android-34, build-tools 34.0.0
./gradlew testDebugUnitTest assembleDebug       # полная сборка: app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleDebug -PbundleModel=false     # облегчённая: модель скачается на телефоне при первом запуске
./gradlew assembleDebug -Pabis=arm64-v8a        # только 64-битные телефоны (на ≈5 МБ меньше)
```

Офлайн-модель (46 МБ) не хранится в git: при полной сборке её скачивает задача `downloadVoskModel` в `app/build/vosk-assets`.

Тесты (`app/src/test`): разбор текста и заголовков, загрузка txt/html/mht и кодировок, сопоставление слов, трекер на шумных
симуляциях (пропуски, неверные окончания, мусор, повторы, заикание, перечитывание, ближний и далёкий перескок, чужая речь, пауза),
проверка на настоящей книге из assets (читается из файла, в коде тестов текста книги нет), статистика, усиление, словарь,
экран приложения (Robolectric). Тест `RealFilesTest` сверяет разбор настоящего `.mht` с вложенным текстом, если задать `MHT_PATH`.

## Структура

```
app/src/main/java/com/alicegpt/textfollower/
  MainActivity.kt         экран: текст, подсветка, оглавление, файлы, настройки
  text/                   Doc (слова, номера строк, заголовки, секции), TextLoader (txt/html/mht), Words
  tracking/               TextTracker (подтверждение позиции), WordMatcher (нечёткое сравнение слов)
  speech/                 VoskEngine (микрофон + Vosk), AutoGain, GrammarBuilder, ModelInstaller
  SessionStats.kt, Settings.kt
tools/vosk-experiment/    скрипты сравнения вариантов словаря
```
